\subsection{Các Bước Triển Khai Hệ Thống}

\begin{enumerate}[leftmargin=*,itemsep=2pt,topsep=2pt]
  \item \textbf{Tải mã nguồn về máy tính:}
\begin{verbatim}
git clone https://github.com/vantruc2206/cong_nghe_phan_mem.git
cd cong_nghe_phan_mem
\end{verbatim}

  \item \textbf{Cấu hình và khởi chạy Backend API (Python Flask):}
\begin{verbatim}
cd backend
python -m venv .venv
source .venv/bin/activate  # Hoặc .venv\Scripts\activate trên Windows
pip install -r requirements.txt
python src/app.py
\end{verbatim}
    \textit{Ghi chú:} Máy chủ Backend sẽ lắng nghe tại địa chỉ \texttt{http://localhost:5000}.

  \item \textbf{Cấu hình và khởi chạy Cổng Khách Hàng (Customer Web Portal):}
\begin{verbatim}
cd "giao diện web khách hàng"
npm install
npm run dev
\end{verbatim}
    \textit{Ghi chú:} Ứng dụng web khách hàng chạy tại địa chỉ \texttt{http://localhost:3000}.

  \item \textbf{Cấu hình và khởi chạy Cổng Quản Trị (Admin Web Portal):}
\begin{verbatim}
cd "Giao diện web quản lý"
npm install
npm run dev
\end{verbatim}
    \textit{Ghi chú:} Ứng dụng quản trị viên chạy tại địa chỉ \texttt{http://localhost:8443}.
\end{enumerate}

\section{Hướng Dẫn Sử Dụng Cổng Khách Hàng (Customer Web Portal)}

Cổng Khách Hàng cung cấp giao diện hiện đại, tối ưu cho thiết bị di động và máy tính, hỗ trợ người dùng thực hiện toàn bộ quy trình từ tạo đơn hàng, theo dõi đường bay Drone đến tương tác với Trợ lý AI.

\begin{enumerate}[leftmargin=*,itemsep=4pt,topsep=2pt]
  \item \textbf{Trang chủ và Tổng quan đơn hàng} \\
  Giao diện chính hiển thị thông điệp chào mừng, thống kê tổng số đơn hàng active (Chờ duyệt, Đang giao, Hoàn thành), các lối tắt thao tác nhanh và danh sách vận đơn gần đây.

    \includegraphics[width=0.75\textwidth,height=7.5cm,keepaspectratio]{so-do/hinh-anh/ảnh giao diện khách hàng/kh_03_trang_chu.png}
    \caption{Giao diện Trang chủ Cổng Khách Hàng}
    \label{fig:cust-home}
  \end{figure}

  \item \textbf{Tạo đơn hàng giao bằng Drone} \\
  Người dùng chọn mục \textit{"Tạo đơn hàng mới"}, nhập thông tin tên kiện hàng, trọng lượng ($\le 5.0$ kg), tên và số điện thoại người nhận. Sử dụng bản đồ Leaflet tích hợp Nominatim Geocoder để chọn điểm giao hàng trực quan. Hệ thống tự động tính cước phí và dự kiến thời gian bay.

    \label{fig:cust-create}
  \end{figure}

  \item \textbf{Quản lý danh sách Đơn hàng của tôi} \\
  Màn hình danh sách đơn hàng cho phép tìm kiếm theo mã đơn, lọc theo trạng thái (Tất cả, Chờ duyệt, Đã duyệt, Đang giao, Đã đến, Hoàn thành). Mỗi thẻ đơn hàng thể hiện rõ tiến trình giao hàng 5 bước và nút hành động tương ứng.

    \label{fig:cust-orders}
  \end{figure}

  \item \textbf{Theo dõi Drone di chuyển thời gian thực (Live Telemetry)} \\
  Khi đơn hàng đang trong quá trình vận chuyển, khách hàng truy cập màn hình \textit{"Theo dõi đơn hàng"} để xem vị trí Drone di chuyển trực quan trên bản đồ. Hệ thống cập nhật tọa độ GPS, mức pin, tên Drone phục vụ và trạng thái đơn hàng thời gian thực.

  Khi Drone đã đáp xuống điểm giao hàng, ứng dụng hiển thị nút \textit{"Xác nhận đã nhận hàng"}. Nhấp vào nút này sẽ kích hoạt hộp thoại xác nhận để hoàn tất đơn hàng và cập nhật trạng thái sang \textit{HOAN\_THANH}.
