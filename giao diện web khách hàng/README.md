# SmartDroneDelivery – Client Web

Bản frontend demo được dựng theo file đặc tả `giao_dien_khach_hang (1).md`.

## Chạy
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt.
3. Nhấn **Dùng tài khoản demo** để vào Dashboard.

## Có sẵn
- Landing Page
- Đăng nhập / Đăng ký
- Dashboard
- Tạo đơn 3 bước
- Danh sách + lọc/tìm kiếm đơn
- Chi tiết đơn + timeline
- Theo dõi drone realtime dạng mô phỏng
- Chatbot UI mô phỏng
- Hồ sơ tài khoản
- Responsive mobile/tablet/desktop
- Các rule: tối đa 5kg, chỉ hủy khi Chờ duyệt, mật khẩu đăng ký tối thiểu 8 ký tự

## Lưu ý
Đây là frontend chạy độc lập. API backend, database, xác thực thật, bản đồ realtime và Groq API chưa được kết nối.
